# Math2You

Proyecto desarrollado en Go para practicar algoritmos matemáticos.

## Funciones actuales

- Factorial
- Hipotenusa
- Ecuaciones cuadráticas
- Método de Gauss para Sistemas de n Ecuaciones
- Máximo Común Divisor (MCD).

## Requisitos

- Go 1.26 o superior

## Ejecutar

```bash
go run .
```

## Compilar

```bash
go build
```
