# Math2You

Proyecto desarrollado en Go para practicar algoritmos matemáticos.

## Funciones actuales

- Factorial
- Hipotenusa
- Ecuaciones cuadráticas
- Método de Cramer
- Máximo Común Divisor (MCD) y muchos mas que se iran creando

## Requisitos

- Go 1.26 o superior

## Ejecutar

```bash
go run .
```

## Compilar

```bash
go build
```
